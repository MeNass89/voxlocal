# Vitrine VoxLocal

Première vitrine publique de l’écosystème de transcription vocale médicale :

- VoxLocal sur macOS ;
- microphone flottant ;
- transcription Whisper et traitement LLM locaux ;
- modes cliniques, collage automatique et historique ;
- capture mobile RemoteScribe ;
- future version Windows ;
- offre Business pour les établissements hospitaliers.

Le symbole « 8 » et l’adresse `contact@voxlocal.ai` sont des éléments provisoires à remplacer avant une publication officielle.

## Prévisualisation

```bash
pnpm install
pnpm run dev
```

## Vérification

```bash
pnpm test
```
